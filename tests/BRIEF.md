# Original brief from the owner (verbatim intent)
Rebuild GAME NIGHT (different games for couples and for friends), bug fixes and an easy flow, to host and share with friends.

DESIGN IDENTITY (most important)
- Must look nothing like a typical Claude or AI-generated app. No default system fonts, no Inter/Roboto/Arial, no purple-to-blue gradients, no generic card grids, no stock rounded-white-box layouts.
- ONE bold aesthetic, committed fully: retro-futurist arcade (1970s TV game show).
- Distinctive display + body font pairing; must differ from his other apps (Big Shoulders Display, Manrope, Bowlby One, Figtree).
- CSS variable system: sharp unusual palette, one signature accent, type scale, spacing, radius, shadow rules, used everywhere.
- One memorable signature detail people ask about. Tasteful motion: page-load reveal, hover/press, smooth transitions; respects prefers-reduced-motion.

USABILITY
- First-time user knows what to do within 5 seconds with no instructions.
- One obvious primary action per screen. Clear hierarchy. Plain-language labels, helpful microcopy, no jargon.
- Friendly empty states, useful error messages that say how to fix the problem, confirmation or undo for destructive actions.
- Mobile-first, fully responsive. Tap targets >= 44px. Works one-handed on a phone.
- Accessible: WCAG AA contrast, visible focus, full keyboard, semantic HTML, alt text, ARIA.
- Fast: no layout shift, instant feedback, optimistic updates where safe.
